# Задача 1. Tracer

## Решение и идея алгоритма

[solution.py](solution.py) содержит декоратор `@tracer` для синхронных функций.
На входе он печатает имя и аргументы, на выходе — имя и результат. Два пробела
соответствуют одному уровню вложенности. Если функция выбросила исключение,
выводится строка `!!` с исключением, затем то же исключение передаётся вызывающему.

```python
from homework_5.tracer.solution import tracer

@tracer
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

assert factorial(3) == 6
```

Алгоритм обёртки:

1. Прочитать текущую глубину и вывести вход с соответствующим отступом.
2. Увеличить глубину на 1 и вызвать исходную функцию с теми же аргументами.
3. Вывести результат либо исключение на уровне входа.
4. В блоке `finally` восстановить прежнюю глубину по токену `ContextVar`.

Общая переменная глубины позволяет показывать вложенные вызовы разных
декорированных функций, включая взаимную рекурсию. `ContextVar` хранит глубину
в текущем контексте, а `functools.wraps` сохраняет имя, документацию и
`__wrapped__`. Возвращаемый объект передаётся без копирования.

Перед вызовом функции глубина равна числу активных обёрток в текущем контексте.
Каждый вход увеличивает её ровно на 1; каждый выход восстанавливает предыдущее
значение, даже при исключении. Поэтому внутренние вызовы получают дополнительный
отступ, а соседние ветви и последующие независимые вызовы начинают с правильного
уровня. Результат получается единственным вызовом исходной функции и возвращается
без изменений.

## Пошаговая визуализация

```text
-> factorial(3)
  -> factorial(2)
    -> factorial(1)
      -> factorial(0)
      <- factorial = 1
    <- factorial = 1
  <- factorial = 2
<- factorial = 6
```

| Шаг | Активный стек | Действие |
| --- | --- | --- |
| 1 | `factorial(3)` | вход на глубине 0 |
| 2 | `factorial(3) → factorial(2)` | вход на глубине 1 |
| 3 | `factorial(3) → factorial(2) → factorial(1)` | вход на глубине 2 |
| 4 | `factorial(3) → factorial(2) → factorial(1) → factorial(0)` | базовый случай, глубина 3 |
| 5 | `factorial(3) → factorial(2) → factorial(1)` | из `factorial(0)` вернулось 1 |
| 6 | `factorial(3) → factorial(2)` | из `factorial(1)` вернулось `1 × 1 = 1` |
| 7 | `factorial(3)` | из `factorial(2)` вернулось `2 × 1 = 2` |
| 8 | пусто | из `factorial(3)` вернулось `3 × 2 = 6` |

Если возникает исключение, вместо нормального возврата на каждом затронутом
уровне печатается, например, `!! factorial raises ValueError('...')`.
Глубина после раскрутки стека снова равна 0.

## Сложность

Пусть `C` — число вызовов, `d` — максимальная глубина, `L` — суммарная длина
выведенного текста с аргументами, результатами и отступами. Управление глубиной
добавляет O(1) времени на вызов. С учётом форматирования и вывода накладные
расходы — **O(C + L)**, если `repr` значений работает за время, пропорциональное
размеру представления. Время самой функции добавляется отдельно.

Обёртки и токены требуют **O(d)** памяти. Дополнительно на активных уровнях
хранятся строки отступов и представления аргументов: **O(d + B)**, где `B` — их
суммарная длина. Даже для коротких аргументов отступы вдоль глубокой цепочки
могут занимать O(d²). Вывод отправляется сразу в `stdout`; накопление вывода
терминалом или тестовым захватом в эту оценку не входит.

Для примера `factorial(n)` при условно постоянной стоимости арифметики:
n + 1 вызовов, O(n) времени без трассировки, O(n) стека. Текст отступов
при трассировке имеет суммарную длину O(n²). Реальные большие целые и их
строковые представления увеличивают стоимость арифметики и вывода.

## Тесты

[test_tracer.py](test_tracer.py) проверяет:

- точный вывод входов и возвратов для `factorial(3)`;
- базовый случай, независимые вызовы и отсутствие лишнего отступа;
- позиционные и именованные аргументы, `*args`, `**kwargs`, вызов без аргументов;
- результат `None`, идентичность возвращаемого объекта и сохранение метаданных;
- распространение исходного исключения и восстановление глубины;
- исключение, перехваченное внешней функцией, и продолжение на прежней глубине;
- общий стек разных декорированных функций и взаимную рекурсию.

Запуск из корня: `python -m pytest homework_5/tracer -q`.
