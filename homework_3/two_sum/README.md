# Two Sum

## Идея решения

Идём по массиву слева направо и храним в хеш-таблице уже просмотренные числа:
`число -> его индекс`. Для текущего `value` вычисляем число, которого не
хватает до суммы: `needed = k - value`. Если `needed` уже есть в таблице,
ответ найден: его индекс обязательно меньше текущего, поэтому индексы сразу
расположены по возрастанию.

Если нужного числа пока нет, сохраняем текущие `value` и индекс. Гарантия из
условия говорит, что подходящая пара ровно одна; при нарушении этой гарантии
функция сообщает об отсутствии пары через `ValueError`.

## Пошаговая визуализация

Пример: `arr = [1, 3, 4, 10]`, `k = 7`.

| Индекс | Текущее число | `needed = 7 - value` | Уже просмотренные числа | Действие |
| --- | --- | --- | --- | --- |
| 0 | `1` | `6` | `{}` | `6` нет: сохранить `1 -> 0` |
| 1 | `3` | `4` | `{1: 0}` | `4` нет: сохранить `3 -> 1` |
| 2 | `4` | `3` | `{1: 0, 3: 1}` | `3` найдено по индексу `1`: ответ `(1, 2)` |

Элемент `10` смотреть не нужно: единственная подходящая пара уже найдена.

Для случая `arr = [5, 5, 1, 4]`, `k = 10` первый `5` сохраняется с индексом
`0`, а при втором `5` находится недостающее число `5`; ответ — `(0, 1)`.

## Сложность

Время — **O(n)** в среднем: один проход по `n` элементам, а поиск и вставка в
хеш-таблицу в среднем занимают **O(1)**. Память — **O(n)** в худшем случае:
до нахождения пары могут быть сохранены все элементы.
