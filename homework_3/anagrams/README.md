# Anagrams

## Идея решения

Для каждого слова создаётся **канонический ключ** — его буквы, отсортированные
по возрастанию. У анаграмм набор букв одинаков, поэтому одинаков и ключ:
`"eat"`, `"tea"` и `"ate"` дают ключ `"aet"`. Хеш-таблица сопоставляет
такому ключу список всех слов с этим ключом.

После группировки слова внутри каждой группы и сами группы сортируются. Это не
обязательно для поиска анаграмм, но делает ответ предсказуемым и соответствует
формату примера: одинаковый набор слов всегда возвращается в одном порядке (также я сортирую итоговый ответ
по своему усмотрению по первому элементу каждой группы анаграм, чтобы ответ был детерминированный,
но в самом условии дополнительных критериев к этому не было).
Регистр учитывается: `"Cat"` и `"cat"` — разные слова.

## Пошаговая визуализация

Пример: `words = ["eat", "tea", "tan", "ate", "nat", "bat"]`.

| Слово | Отсортированные буквы (ключ) | Группы после добавления |
| --- | --- | --- |
| `eat` | `aet` | `{aet: [eat]}` |
| `tea` | `aet` | `{aet: [eat, tea]}` |
| `tan` | `ant` | `{aet: [eat, tea], ant: [tan]}` |
| `ate` | `aet` | `{aet: [eat, tea, ate], ant: [tan]}` |
| `nat` | `ant` | `{aet: [eat, tea, ate], ant: [tan, nat]}` |
| `bat` | `abt` | `{aet: [eat, tea, ate], ant: [tan, nat], abt: [bat]}` |

После сортировки внутри групп получаем
`[["ate", "eat", "tea"], ["bat"], ["nat", "tan"]]`.

## Сложность

Пусть `n` — число слов, а `L` — средняя длина слова. Сортировка букв каждого
слова занимает **O(L log L)**, поэтому формирование групп —
**O(n · L log L)** по времени. Сортировка итоговых групп добавляет не более
**O(n log n)** сравнений строк. Память — **O(n · L)** для ключей и групп.
