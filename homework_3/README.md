# Домашнее задание №3

## Запуск

- `./setup.sh` — создать виртуальное окружение и установить `pytest`.
- `./run_tests.sh` — запустить тесты всех задач.

В каждой папке находятся решение, тесты и `README.md` с объяснением алгоритма,
оценкой сложности и пошаговой визуализацией.

## Задачи

- `two_sum/` — поиск двух индексов с заданной суммой;
- `anagrams/` — группировка анаграмм;
- `hash_table/` — собственная хеш-таблица на списках.
