# Домашнее задание №2

## Запуск

- `./setup.sh` — создать виртуальное окружение и установить `pytest`.
- `./run_tests.sh` — запустить тесты всех трёх задач.

Каждая папка задачи содержит `README.md` с объяснением, оценкой сложности и
пошаговой визуализацией, а также `solution.py` и тесты.

## Задачи

- `stack_vs_queue/` — стек и очередь на односвязных списках;
- `validate/` — проверка допустимой последовательности извлечений из стека;
- `merge_lists/` — слияние двух отсортированных односвязных списков двумя способами.
